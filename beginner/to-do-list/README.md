# To-Do List 📝

A simple command-line To-Do List application built with Python.

This program allows users to manage their daily tasks through a text-based menu. Users can add, view, delete, complete, and undo task completion.

## Features

- Add new tasks
- Display all tasks
- Delete existing tasks
- Mark tasks as completed
- Undo task completion
- Input validation
- Error handling for invalid inputs
- Prevent empty tasks

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/Narges-daneshi/mini-python-projects.git
   ```

2. Navigate to the project directory:

   ```bash
   cd mini-python-projects/beginner/to-do-list
   ```

3. Run the program:

   ```bash
   python main.py
   ```

## Concepts Used

- Functions
- Lists and Dictionaries
- Loops and Conditional Statements
- String Methods
- List Manipulation
- Exception Handling (`try-except`)
- Input Validation
- Python Built-in Functions

## Limitations

Tasks are stored in memory and will be lost when the program exits. Data persistence is not implemented yet.
