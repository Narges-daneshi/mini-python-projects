# Word Guessing Game 🎮

A simple command-line word guessing game built with Python.

The program randomly selects a word, and the player tries to guess it one letter at a time. Players have a limited number of incorrect guesses to discover the hidden word.

## Features

- Random word selection
- Input validation
- Prevention of repeated guesses
- Tracking correct and incorrect guesses
- Limited number of incorrect attempts
- Displaying game statistics
- Revealing the correct word when the game ends

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/Narges-daneshi/mini-python-projects.git
   ```

2. Navigate to the project directory:

   ```bash
   cd mini-python-projects/beginner/word-guessing-game
   ```

3. Run the program:

   ```bash
   python main.py
   ```
